# Regret Meter UI plan

The interface is a playful cyber-glass decision cockpit rather than a marketing landing page. Hot pink, electric lime, bright cyan, and neon amber create visibly different hazard states. Evaluation, overall percentage, Bob's thinking pathway, forensic reporting, and clearly labeled history actions share one workspace; the Bob Co-Pilot floats persistently across every view.

Primary flow: describe decision → set horizon and emotion → audit → inspect forensic report → sign in to save/export → revisit history or question assumptions with the Decision Co-Pilot.
